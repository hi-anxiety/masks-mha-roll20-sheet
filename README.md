# MHA-Inspired Masks Roll20 Character Sheet

An unofficial fan-made Roll20 character sheet for running
**Masks: A New Generation** in a superhero-academy setting inspired by
**My Hero Academia**.

## Features

- Character Info, Quirk Info, and Playbook Info tabs
- MHA-inspired visual design
- Favorite Color background themes
- Quirk strengths, weaknesses, development, and Ultimate Moves
- Repeating Relationships and Ultimate Move entries
- Support for the existing Masks playbook mechanics

## Installation

This sheet requires a Roll20 account with access to Custom Character Sheets.

1. Open your game's **Character Sheet Template** settings.
2. Choose **Custom**.
3. Enable **Legacy** mode.
4. Paste `masks-mha.html` into the HTML tab.
5. Paste `masks-mha.css` into the CSS tab.
6. Paste `translation.json` into the Translation tab.
7. Save changes and reload your game.

**Important:** The sheet was built for Roll20's Legacy custom sheet system.
It will not display correctly in the newer custom sheet mode.

## House Rules

The sheet includes space for campaign-specific MHA-style mechanics such as
Ultimate Moves. These are optional additions and are not part of the
standard Masks rules.
